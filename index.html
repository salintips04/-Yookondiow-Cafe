ชื่อร้านค้า

ชื่อร้านจะแสดงที่หัวเว็บ ชื่อแท็บเบราว์เซอร์ และหัวใบเสร็จ

อัปโหลดโลโก้ร้าน (jpg/png) จะแสดงแทนไอคอน ☕ ที่หัวเว็บและใบเสร็จ

รับชำระเงิน (QR code ในใบเสร็จ)

อัปโหลดรูปภาพ QR code พร้อมเพย์ของร้าน (ถ่ายรูปหรือแคปจากแอปธนาคาร) เพื่อแสดงในใบเสร็จทุกใบ ให้ลูกค้าสแกนจ่ายเอง

ไม่อัปโหลด = ใบเสร็จจะไม่มี QR code

ธีมสีร้าน

เลือกโทนสีของเว็บให้เข้ากับร้านคุณ

ข้อมูล

ข้อมูลทั้งหมดถูกเก็บไว้ในเบราว์เซอร์นี้เท่านั้น (localStorage) ไม่มีการส่งข้อมูลออกอินเทอร์เน็ต หากล้างแคช/ข้อมูลเว็บไซต์ของเบราว์เซอร์ ข้อมูลจะหายถาวร แนะนำให้กด "ดาวน์โหลดข้อมูลสำรอง" เก็บไว้เป็นประจำ (เช่น ทุกสิ้นวัน) เพื่อกู้คืนได้ภายหลัง

จัดการหมวดหมู่

เพิ่มหมวดหมู่ได้โดยไม่ต้องผูกกับสินค้า และจะอยู่ในลิสต์ตลอดจนกว่าจะลบเอง

รวม:

จัดการท็อปปิ้ง

เพิ่มท็อปปิ้งพร้อมราคา และเลือกหมวดหมู่ที่จะใช้ท็อปปิ้งนี้ได้ ลูกค้าจะเห็นเฉพาะท็อปปิ้งที่ตรงกับหมวดหมู่ของสินค้านั้น
